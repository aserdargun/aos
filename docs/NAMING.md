# İsim: AOS — Agent Operating System

**Kod:** `aos` · **Klasör/repo:** `aos-aserdargun-com` · **ZIP:** `aos-aserdargun-com.zip`

Ürünün kalıcı çekirdeğini, yerel ajan işletim ortamını ve öğrenme platformunu birlikte anlatır. Önceki konuşmada seçilen adı korur; Bonsai veya tek bir GUI özelliğine bağlanmaz. “OS” burada Linux kernel/distro değil, ajan runtime ve kontrol platformudur.

Kullanıcının üç harfli sistematiği açık talebi nedeniyle kişisel web uygulamalarındaki repo biçimi bu yerel platforma da uygulanmıştır. Bu biçim Azure veya website deployment kararı değildir.

Puanlama: mnemonic×5 + kapsam×4 + teknik güven×3 + marka×3 + genişleme×3 + çakışmasızlık×2. Puanlar tasarım değerlendirmesidir, ölçüm değildir.

|---|---:|---:|---:|---:|---:|---:|---:|

LAR çalışma ortamını iyi açıklar ama learning/UI kapsamını geri plana atar. LAC bilgisayar katmanına daralır. ALP öğrenmeyi öne çıkarırken bilgisayar kullanım platformunu daha az anlatır.

Diğer taranan adaylar: lao, dao, las, air, arc, sys. `dao` yerleşik decentralized organization çağrışımı, `sys` aşırı genel teknik isim, `aia` ve `llm` mevcut ayrılmış kodlarla çakışma nedeniyle elenir. `lao/las/air/arc` AOS kadar açık mnemonic oluşturmadı.

Çakışma kontrolü kullanıcının mevcut isimlendirme belleğindeki aia, llm, stk, usl, gpu, inf, nxt ve bilinen portföy kodlarıyla sınırlıdır. GitHub/DNS/marka müsaitliği canlı kontrol edilmedi; AOS için küresel benzersizlik veya alan adı müsaitliği iddia edilmez.
