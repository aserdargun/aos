trusted production prelaunch/activation composition, physical handover or real
worker coexistence is claimed. The concrete CPU-service factory preserves the existing authenticated console,
approval and journal paths; its ASGI tests use a fixture controller and mocked
Scientist responses; separate real CPU/API evidence is bounded as described above.
Typed field-intent and selected-experience forwarding is implemented in the
isolated source with structured EN/TR controls and legacy-byte compatibility;
see [task context](../SCIENTIST_TASK_CONTEXT.md) and dated validation in STATUS.
Explicit CPU fixture desktop startup wiring now exists in source, preserving
typed review, approval, intent and local cleanup. It is not deployed. Actual optional-context acceptance and active-Scorer
interruption remain separate work. Historical native results and synthetic tests
are not current deployment evidence.

Authorized target-web workflows/specialization, learning quality/promotion,
clean-host GPU reproducibility and target-user delivery retain their own gates.
SWAPP requires separately authorized intranet/data/task-oracle access and comes
last. License selection and applicable third-party/model rights remain pending;
public source is not an approved open-source license or production SLA.
