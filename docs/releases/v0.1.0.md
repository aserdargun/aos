**3 October 2026: release note for a planned tag, not a published Git release.**
The tested public source baseline is commit `931b55e`; later reviewed additive
changes and this note must enter the final coherent source commit before tagging.

## Delivery scope

Source contracts, canonical schemas/migrations, explicitly synthetic fixtures,
authorized task/control paths, durable Scientist Lab intent/readback integration,
and bounded CPU-tested handover/exclusion and CPU-capability components are
provided for inspection, testing and continued development. Exact final source
and manifest identity belong to the release-owner packaging record, not an
inferred tag target. No private models, datasets, trajectories, credentials,
screenshots, local databases or runtime authority are supplied.

The six [full-product acceptance stages](../RELEASE_ACCEPTANCE.md) remain open.
This source/prototype version does not require completing the future Scientist
and web-specialization phase or deferred company-intranet SWAPP integration;
it does not mark those stages complete or change their safety gates.

## Known limitations

No current shared Scientist/GPU end-to-end acceptance, executed native maintenance,
trusted production prelaunch/activation composition, physical handover or real
worker coexistence is claimed. The CPU-capability adapter is source-tested;
The concrete CPU-service factory preserves the existing authenticated console,
approval and journal paths; its ASGI tests use a fixture controller and mocked
Scientist responses. Deployed startup wiring, typed field-intent forwarding and
inflight cancellation and final owned cleanup remain separate work. Historical native results and synthetic tests
are not current deployment evidence.

Authorized target-web workflows/specialization, learning quality/promotion,
clean-host GPU reproducibility and target-user delivery retain their own gates.
SWAPP requires separately authorized intranet/data/task-oracle access and comes
last. License selection and applicable third-party/model rights remain pending;
public source is not an approved open-source license or production SLA.
